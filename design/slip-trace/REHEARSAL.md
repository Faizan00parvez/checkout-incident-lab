# Receipt illustration

The homepage uses a still adapted from the Stageshow static-card example. Its selected order and receipt show the published incident timings. The underlying window extends past the frame, while the receipt stays readable at both sizes.

Place this folder at examples/slip-trace in the Stageshow playground to edit it. The two static layouts passed the film rehearsal gate at desktop and 390 px. The site serves WebP exports so the illustration works without JavaScript. Motion belongs to the incident player below it.
